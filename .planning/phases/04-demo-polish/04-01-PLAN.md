# Plan 04-01: Automated E2E Verification Suite for Definition of Done

## Objective
Create an automated end-to-end verification script (`scripts/verify-e2e.mjs`) that exercises the entire NapkinCloud compiler, validation, synthesis, and execution pipeline, asserting that the 9-step Definition of Done passes programmatically.

## Code Patterns (Model Resilience)
Conventions:
- Standalone Node.js ESM script: `node scripts/verify-e2e.mjs`
- Direct import of compiled or library modules: `src/lib/validator.ts`, `src/lib/bedrock.ts`, `src/lib/compiler.ts`, `src/lib/lambdaSynthesizer.ts`, `src/lib/dataStore.ts`
- Exit code 0 on all tests passing, non-zero on failure
