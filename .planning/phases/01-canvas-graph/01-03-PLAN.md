# Plan 01-03: Sidebar Drag-and-Drop & Graph JSON Exporter

## Objective
Build the component palette sidebar allowing users to drag and drop AWS components onto the canvas. Implement the top navigation bar with project title and action buttons, and build the graph serialization utility that transforms canvas state into strict Graph JSON ready for the Phase 2 AI compiler.

## Code Patterns (Model Resilience)
Conventions:
- HTML5 Drag and Drop API: `event.dataTransfer.setData('application/reactflow', nodeType)`
- React Flow screen-to-flow coordinate conversion: `reactFlowInstance.screenToFlowPosition({ x: event.clientX, y: event.clientY })`
- Serialization helper: pure function in `src/lib/graphExporter.ts`
