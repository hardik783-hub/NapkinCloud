# Plan 01-02: Custom AWS Nodes & Connection Constraints

## Objective
Create custom React Flow node components for `API Gateway`, `Lambda`, and `DynamoDB` with AWS-branded icons, editable property fields (route, method, function name, table name, partition key, business logic note), and strict connection rules to prevent invalid architectures.

## Code Patterns (Model Resilience)
Conventions:
- Type definitions: `src/types/canvas.ts` defining node data schemas and node types (`api_gateway`, `lambda`, `dynamodb`)
- Handles: Use `@xyflow/react` `<Handle type="source" position={Position.Right} />` and `<Handle type="target" position={Position.Left} />`
- State propagation: Custom nodes update their own node data using React Flow's `useReactFlow().setNodes` callback
