# Plan 01-01: Project Scaffold & React Flow Dark Canvas

## Objective
Initialize the Next.js project with TypeScript, Tailwind CSS, `@xyflow/react`, and `lucide-react`. Create the foundational dark-mode interactive canvas component with dot grid background, controls, and responsive zoom/pan navigation.

## Code Patterns (Model Resilience)
Conventions:
- Next.js 14+ App Router with `'use client'` on interactive canvas components
- Styling: Tailwind CSS with dark palette (`slate-950` background, `slate-800` borders, `cyan-500` / `emerald-500` accents)
- Canvas wrapper: Full viewport height (`h-screen w-screen overflow-hidden`)

<task type="auto">
  <name>Build Interactive Dark-Mode Canvas Base</name>
  <files>src/components/canvas/Canvas.tsx, src/app/page.tsx</files>
  <action>
    1. Create `src/components/canvas/Canvas.tsx` as a Client Component (`'use client'`).
    2. Import `ReactFlow`, `Background`, `Controls`, `BackgroundVariant`, `useNodesState`, `useEdgesState` from `@xyflow/react`.
    3. Initialize empty nodes and edges state.
    4. Render `<ReactFlow>` with dark background dot pattern (`variant={BackgroundVariant.Dots}`), dark mode styling, and zoom/pan controls.
    5. Wire `src/app/page.tsx` to render `<Canvas />`.
  </action>
  <verify>npm run build</verify>
  <done>Root page renders a full-screen interactive React Flow canvas with dot grid and controls</done>
</task>
