# Plan 05-01: Prompt-to-Canvas & AI Reasoning Engine

## Objective
Implement Hardik's schemas and Prompt-to-Architecture idea: allow natural language input to auto-draw the backend architecture canvas, provide an AI Reasoning breakdown in the compilation modal, and unify export JSON with the teammate's exact schema.

## Tasks
1. Create `src/lib/architectureGenerator.ts` with Bedrock Claude 3.5 Sonnet prompt normalizer and instant fallback engine.
2. Create `src/app/api/generate-architecture/route.ts` API route.
3. Update `src/lib/graphExporter.ts` to output Hardik's `application`, `architecture`, and `reasoning` schema.
4. Create `src/components/canvas/PromptBar.tsx` floating UI with preset prompt chips.
5. Integrate `PromptBar` into `Canvas.tsx` to dynamically set nodes, edges, and reasoning.
6. Add AI Reasoning card to `CompilationModal.tsx`.
7. Verify with `npm run test:e2e` and `npm run build`.
