# Plan 02-02: Deterministic SAM Compiler & Lambda Synthesizer

## Objective
Build the deterministic SAM template compiler that injects normalized parameters into tested CloudFormation structures with hardcoded CORS and least-privilege DynamoDB policies, and the Lambda code synthesizer that writes production-ready Node.js handlers.

## Code Patterns (Model Resilience)
Conventions:
- SAM Template: YAML generation using deterministic template strings (avoiding YAML syntax errors)
- Lambda runtime: `nodejs20.x` with `@aws-sdk/client-dynamodb` and `@aws-sdk/lib-dynamodb`
- Output formatting: Standalone `template.yaml` and `index.js` strings ready for CloudFormation packaging

## Tasks

<task type="auto">
  <name>Build Lambda Code Synthesizer</name>
  <files>src/lib/lambdaSynthesizer.ts</files>
  <action>
    1. Create `synthesizeLambdaCode(normArch)`:
       - Imports `DynamoDBClient` from `@aws-sdk/client-dynamodb`.
       - Imports `DynamoDBDocumentClient` and `PutCommand` / `ScanCommand` from `@aws-sdk/lib-dynamodb`.
       - Generates `exports.handler = async (event) => { ... }`:
         - Parses incoming JSON body from API Gateway event.
         - Validates primary key presence or auto-generates UUID via `crypto.randomUUID()`.
         - Injects Bedrock's extracted business logic.
         - Executes `PutCommand` against the dynamic `process.env.TABLE_NAME`.
         - Returns CORS-compliant HTTP response `{ statusCode: 200, headers: { 'Access-Control-Allow-Origin': '*' }, body: JSON.stringify(...) }`.
         - Wraps in try/catch returning `{ statusCode: 500 }` on database failure.
  </action>
  <verify>npm run build</verify>
  <done>Lambda synthesizer generates clean, error-handled Node.js 20.x handler code</done>
</task>

<task type="auto">
  <name>Build Deterministic SAM Compiler & Fallback Engine</name>
  <files>src/lib/compiler.ts, src/lib/fallbackTemplate.ts</files>
  <action>
    1. Create `src/lib/fallbackTemplate.ts` containing the known-good base SAM template for `API Gateway -> Lambda -> DynamoDB` with `BillingMode: PAY_PER_REQUEST` and permissive CORS.
    2. Create `src/lib/compiler.ts` with `compileSamTemplate(normArch, projectId)`:
       - Generates sanitized CloudFormation logical IDs: `HttpApi`, `${SafeName}Function`, `${SafeTable}Table`.
       - Wires the HTTP API event trigger to the Lambda function on route `${normArch.api.path}` with method `${normArch.api.method}`.
       - Attaches `DynamoDBCrudPolicy` scoped strictly to the generated table name.
       - Generates Outputs section exporting `ApiEndpoint`, `FunctionName`, `TableName`.
       - Emits clean, validated YAML string.
  </action>
  <verify>npm run build</verify>
  <done>Deterministic compiler emits valid AWS SAM YAML templates with CORS and IAM policies</done>
</task>
