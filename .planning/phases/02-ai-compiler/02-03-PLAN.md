# Plan 02-03: Compilation API Route & Canvas Hand-Off Integration

## Objective
Implement the Next.js `/api/compile` route connecting the validator, Bedrock normalizer, and SAM compiler. Wire the frontend TopBar action so clicking "⚡ Compile to AWS" transitions node states, generates the real infrastructure artifacts, and opens the compilation result drawer.

## Code Patterns (Model Resilience)
Conventions:
- Next.js Route Handler: `export async function POST(req: Request)`
- JSON payload responses with standardized error envelopes
- State updates: Canvas sets nodes to `compiling` during API fetch, and reverts to `draft` or advances based on response

  <action>
    1. Create `POST /api/compile`:
       - Accepts `{ projectId, nodes, edges }` JSON body.

       - Handles unexpected server errors gracefully with 500 status.
  </action>
