# Plan 03-01: Live Node Status Transitions & Control Surface Hooks

## Objective
Implement dynamic node status state transitions (`draft` -> `compiling` -> `deploying` -> `🟢 live`) and the interaction hooks so that once live, clicking on an active API Gateway or DynamoDB node opens the respective inspector drawer.

## Code Patterns (Model Resilience)
Conventions:
- Status transitions: Managed in `Canvas.tsx` with clear timers for realistic visual deployment feedback (`deploying` for 3.5s before transitioning to `live`)
- Live URLs: Assign realistic AWS URLs (`https://${id}.execute-api.us-east-1.amazonaws.com/prod/orders`) and table ARNs
- `onNodeClick` handler on `<ReactFlow>` opening the corresponding drawer
