# Plan 03-02: Slide-Out In-Canvas API Tester Drawer

## Objective
Build the slide-out API Tester drawer that allows users to fire live HTTP payloads directly from the canvas API Gateway node, accompanied by a backend `/api/test` proxy route that executes the request, tracks latency, and returns live JSON responses.

## Code Patterns (Model Resilience)
Conventions:
- Slide-out panel: `fixed right-0 top-0 bottom-0 w-full max-w-md bg-slate-900 border-l border-slate-800 z-40 shadow-2xl transition-transform`
- Execution API: `POST /api/test` returning `{ success: true, statusCode: 200, latencyMs: number, body: object }`
- Event emission: Calling an `onRecordCreated(record)` callback to notify the DynamoDB store
