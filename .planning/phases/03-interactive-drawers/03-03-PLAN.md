# Plan 03-03: Slide-Out DynamoDB Inspector Drawer & Real-Time Sync

## Objective
Build the in-canvas DynamoDB Inspector drawer that queries and visualizes live table items in a clean dark table UI. Implement real-time synchronization so that executing a request from the API tester drawer immediately updates the DynamoDB table view.

## Code Patterns (Model Resilience)
Conventions:
- In-memory persistent data store in `src/lib/dataStore.ts` holding items per project/table
- Route handler: `GET /api/data` returning `{ success: true, items: Record<string, any>[] }`
- Table rendering: Responsive table with clean monospace typography, badge statuses, and copyable item IDs
